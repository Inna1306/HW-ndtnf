# Books App

## Требования

- **Node.js** ≥ 18
- **npm** ≥ 9 (или `yarn` / `pnpm`)

## Установка
### Установка зависимостей

npm install

### Nest CLI (если еще не установлен глобально):

npm install -g @nestjs/cli

## Запуск

### Режим разработки 

npm run start:dev

### Обычный запуск

npm run start

### Продакшн-сборка

npm run build
npm run start:prod

### После запуска приложение доступно по адресу: **http://localhost:3000**
